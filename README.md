# claude-skills — общие своды правил x10company

Плагин Claude Code. Своды, применимые в **любом** нашем репозитории, живут
здесь в одном экземпляре, а не копиями по проектам.

| Свод | О чём |
|---|---|
| `proverki` | почему проверка сказала «чисто», а чисто не было; как заслужить зелёный результат |
| `obolochka-i-git` | heredoc и слэши, переносы строк, кодировки, `git add -A`, смешение алфавитов |
| `hod-raboty` | ведение работы: список задач, чего делать НЕ надо, приёмка, коммиты |
| `karpathy-guidelines` | внешний набор: думать до кода, простота, хирургические правки |

## Подключить

**Человеку, один раз на машину:**

```
/plugin marketplace add x10company/claude-skills
/plugin install x10-obshchie@x10company
```

**Репозиторию — тогда всякий, кто его откроет, получит своды сам.**
В `.claude/settings.json` проекта:

```json
{
  "extraKnownMarketplaces": {
    "x10company": {
      "source": { "source": "github", "repo": "x10company/claude-skills" }
    }
  },
  "enabledPlugins": { "x10-obshchie@x10company": true }
}
```

**Организации** — те же два ключа в управляемых настройках; тогда своды
появляются у всех при запуске, и делать никому ничего не надо.

## Что сюда не кладём

Всё, что верно только для одного хозяйства: устройство конкретных рантаймов,
пути к секретам, правила по конкретным внешним системам. Такому место в
`.claude/skills/` своего репозитория.

Проверка простая: свод годится сюда, если он остаётся верным в проекте, где
нет ни Airtable, ни Keitaro, ни нашей апишки.
